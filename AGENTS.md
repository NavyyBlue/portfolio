# Project workflow

Before changing implementation code for any feature or other functional change, use OpenSpec.

1. Start with the `openspec-propose` workflow and complete its required planning artifacts.
2. Do not implement the change in the proposal step.
3. Implement only in a follow-up step using the `openspec-apply-change` workflow.

Keep bootstrap-only or documentation-only maintenance outside this workflow when it does not change project behavior.
